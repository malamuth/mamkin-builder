## CART-001 — нормализация имени в customer_label

Статус: `active`.

Результат: `customer_label` убирает внешние и повторяющиеся пробелы в имени, сохраняя регистр. Для пустого имени возвращает `Customer: ` с ровно одним пробелом после двоеточия.

Критерии готовности:

- Внешние пробелы удалены, повторяющиеся пробелы между частями имени сведены к одному.

- Пустое имя и имя только из пробелов дают `Customer: ` (последний символ — пробел).
