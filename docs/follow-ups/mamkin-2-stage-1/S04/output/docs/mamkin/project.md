# Проект Cart

Цель: локальный расчёт корзины и формирование подписи клиента.

## Источники и ограничения

- [README](../../README.md) — описание корзины: суммы в целых центах, строка содержит цену единицы и количество; сеть, аккаунты и сервисы не нужны.
- [AGENTS.md](../../AGENTS.md) — обязательные ограничения и команда проверки. Только стандартная библиотека Python; сохранять пользовательские изменения; не публиковать, не устанавливать зависимости, не обращаться к внешним сервисам.
- [cart.py](../../cart.py) — текущая реализация; [tests/test_cart.py](../../tests/test_cart.py) — существующие проверки.
- [owner-notes.md](../../owner-notes.md) — пользовательский черновик; сохранять дословно.
- [Текущая задача](work.md) — требования и разрешённый объём продолжения.

Работа разрешена только в текущем каталоге проекта. Внешние действия не разрешены.

## Решения и состояние настройки

- Mamkin 2.0 использует эти две записи и существующие локальные навыки [mamkin-setup](../../.agents/skills/mamkin-setup/SKILL.md) и [mamkin-work](../../.agents/skills/mamkin-work/SKILL.md). Дополнительные инструменты и служебные слои не нужны для передачи одной задачи между чатами.
- При настройке была разрешена только подготовка контекста. По последующим запросам пользователя выполнена MAM-001; результат и границы разрешений записаны в [текущей задаче](work.md).
- При настройке уже существовали незакоммиченные изменения в `cart.py` (константа `OWNER_LABEL = 'draft retain'`), неотслеживаемые `owner-notes.md` и `.agents/`. Они сохранены без изменений.
- Исходная проверка по команде из AGENTS.md прошла: 2 теста, `OK`. Это проверка существующего состояния, не подтверждение выполнения текущей задачи.

Установка зависимостей не требуется. Отдельная команда запуска приложения не документирована; сейчас проект представлен функциями Python и тестами. Блокирующих вопросов для настройки нет.
