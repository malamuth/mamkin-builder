# Контекст проекта

## Решения и ограничения

- Стек пока не выбран: проект находится на этапе определения идеи.
- В рамках настройки разрешено только сохранить контекст и записи о работе. Пользователь запретил установки и начало реализации.
- Текущей продуктовой задачи нет; настройка не даёт разрешения начинать следующую задачу или выполнять внешние действия.
