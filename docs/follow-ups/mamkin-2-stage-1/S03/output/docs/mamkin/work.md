## MAM-001 — Нормализация имени в customer_label

Статус: `active`.

Результат: `customer_label` убирает внешние и повторяющиеся пробелы в имени, сохраняя регистр, и формирует подпись клиента.

Критерии готовности:

- Внешние пробелы удалены, повторяющиеся пробелы внутри имени сведены к одному.
- Регистр имени сохранён. Например, имя `  aDa   Lovelace  ` даёт `Customer: aDa Lovelace`.
- Пустое имя, в том числе имя из одних пробелов, даёт ровно `Customer: `: один пробел после двоеточия.
- Проверки покрывают эти случаи, а команда из [AGENTS.md](../../AGENTS.md) проходит.
- Существующие пользовательские изменения сохранены.

Разрешённый объём текущего сеанса: по запросу пользователя выделить и проверить только helper `clean_name`, затем остановиться до его подключения к `customer_label`. Задачу оставить активной и сохранить точку продолжения для нового чата. Соседние задачи не выполнять. Работать только в текущем каталоге проекта, без внешних действий.

Прогресс: в `cart.py` добавлен отдельный `clean_name(name)`, использующий `' '.join(name.split())`. Он удаляет внешние и повторяющиеся пробельные символы, сохраняет регистр и возвращает пустую строку для пустого или пробельного имени.
