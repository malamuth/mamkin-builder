# Mamkin 2.0 Результаты этапа 1

Дата: 2026-11-10. Статус: этап 1 завершён на ограниченном синтетическом наборе. Этап 2 не начат.

Реализованы два самодостаточных Codex skills: [mamkin-setup](../../../.agents/skills/mamkin-setup/SKILL.md) и [mamkin-work](../../../.agents/skills/mamkin-work/SKILL.md). Финальная версия прошла восемь новых сеансов Codex CLI, включая фактическую частичную работу, сохранение точки остановки и продолжение в другом чате без передачи истории.

Требования: [границы этапа](../../project/mamkin-2-stage-1.md), [план MVP](../../project/mamkin-2-mvp-plan.md). Критерии: [набор проверки](../../../evals/mamkin-2/stage-1/README.md). Данные: [manifest.json](manifest.json). Независимое статическое review: [review.md](review.md).

## Поставка

В целевой проект копируются только две директории `.agents/skills/mamkin-setup/` и `.agents/skills/mamkin-work/`. В каждой один `SKILL.md`; продуктовых scripts, presets, hooks, отдельных ролей и зависимости от legacy-процесса нет.

Setup сохраняет существующие инструкции и источники, создаёт минимальные `docs/mamkin/project.md` и `work.md`, дополняет `AGENTS.md` ссылками и останавливается до реализации. Повторный setup не переписывает подходящие записи. Неизвестные команды остаются неизвестными.

Work выполняет или продолжает одну задачу, сохраняет ID, критерии, текущий статус, прогресс, проверку и следующий шаг. Сначала восстанавливает текущий блокер; устаревшие агентные заметки сводит к актуальному состоянию, сохраняя решения и пользовательскую историю.

Автоматическое прохождение очереди и этапов ещё не реализовано. Источники Mamkin 1.x сохраняются в development-репозитории, но в целевые проекты не копируются и не являются зависимостью новых skills. Миграция Mamkin 1.x не заявляется.

## Доказательство нового чата

- Каждый случай — отдельный `codex exec --ephemeral`, без `resume`, `fork`, предыдущих ответов и пересказа задачи.
- Восемь наблюдаемых thread ID различны; в manifest сохранены их hashes.
- Все текстовые входные файлы S04 точно равны фактическим выходным файлам S03. Оператор не создавал подготовленный checkpoint и не менял файлы между ними.
- S04 получил только: «Используй $mamkin-work и продолжи текущую задачу». Цель и прогресс восстановлены из файлов.
- S03 намеренно остановлен после реального изменения и проверки helper. Это сохранённая пауза и новый независимый чат, не проверка crash или длинного контекста.

Условия: `codex-cli 0.167.0-alpha.3.2`, запрошенные `gpt-6.1-sol/high`, обычные approvals и user rules, sandbox модели `workspace-write`. Пользовательское окружение сохранялось; полный injected context CLI не раскрывается. Настройки доступа не ослаблялись, credentials не копировались, публикация не выполнялась.

## Проверки и телеметрия

- Оба skills прошли штатный `skill-creator/scripts/quick_validate.py`. PyYAML 6.0.3 был установлен только во временный каталог валидатора; зависимостью продукта не стал.
- `scripts/validate_prompt_contracts.py` прошёл. Это структурная проверка development-процесса, не повтор всех legacy-сценариев поведения.
- Контроли harness: правильная частичная реализация проходит, отсутствие helper и повреждение заметки выявляются, вставка ссылки сохраняет инструкции, sandbox запрещает запись и сеть.
- Финальный набор: 8 завершённых запусков, 44 completed command events, 423.264 секунды CLI с инструментами. Это не изолированная latency и не число всех tool calls.
- Отчётные input tokens: 907842, включая 781312 cached; output: 13685. Cached уже входят в input. Стоимость недоступна.
- Метрики первого прогона хранятся отдельно. Ненужных согласований внутри оценённых задач не обнаружено.

## Граница результата

Подтверждены setup, одна задача, фактическая пауза и новый чат, сохранность изменений, неизвестные команды и восстановление blocked-задачи. По одному финальному запуску на случай; все проекты синтетические. Реальный проектный пилот остаётся этапом 3.

Не доказаны статистическая надёжность, crash recovery, длинный контекст или сравнительный выигрыш относительно этапа 0: задачи и методика отличаются. Готовность всего MVP не объявляется.
