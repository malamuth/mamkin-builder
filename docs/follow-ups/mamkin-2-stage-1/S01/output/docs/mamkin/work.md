# Текущая работа

## MAM-001 — Нормализация имени в customer_label

Статус: `queued`.

Результат: `customer_label` убирает внешние и повторяющиеся пробелы в имени, сохраняя регистр, и формирует подпись клиента.

Критерии готовности:

- Внешние пробелы удалены, повторяющиеся пробелы внутри имени сведены к одному.
- Регистр имени сохранён. Например, имя `  aDa   Lovelace  ` даёт `Customer: aDa Lovelace`.
- Пустое имя, в том числе имя из одних пробелов, даёт ровно `Customer: `: один пробел после двоеточия.
- Проверки покрывают эти случаи, а команда из [AGENTS.md](../../AGENTS.md) проходит.
- Существующие пользовательские изменения сохранены.

Разрешённый объём: сейчас только настройка Mamkin 2.0. Реализацию и изменение тестов не начинать. После отдельного запроса на продолжение выполнять одну задачу MAM-001 через [$mamkin-work](../../.agents/skills/mamkin-work/SKILL.md); другие изменения продукта не входят в объём. Работать только в текущем каталоге проекта, без внешних действий.

Прогресс: контекст и требования записаны; код и тесты не изменялись. Существующие 2 теста прошли при настройке; они пока не проверяют нормализацию пробелов.

Следующее действие: после запроса пользователя на реализацию прочитать локальный `mamkin-work`, выполнить MAM-001, проверить результат и обновить эту запись. Блокирующих вопросов нет.
